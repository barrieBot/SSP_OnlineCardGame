All cards

Numeric Scissor Cards

Diese Karten repräsentieren die Schere und tragen jeweils einen Zahlenwert von 1 bis 9.
Sie können Papierkarten jeder Zahl schlagen, unterliegen aber Steinkarten.
Eine Scherenkarte kann nur auf eine Karte gelegt werden, die entweder ebenfalls eine Schere oder ein Papier ist.
Dabei gilt: Sie darf nur gelegt werden, wenn ihr Zahlenwert gleich oder höher ist als der der liegenden Karte.
Beispiel: Liegt eine Schere 2, darf eine Schere 3 oder höher daraufgelegt werden.

Numeric Stone Cards

Steinkarten besitzen ebenfalls einen Zahlenwert zwischen 1 und 9.
Sie schlagen Scherenkarten, sind jedoch schwächer als Papierkarten.
Eine Steinkarte kann nur auf eine andere Stein- oder Scherenkarte gelegt werden.
Auch hier muss der Zahlenwert gleich oder höher sein als der der vorherigen Karte.
Beispiel: Liegt ein Stein 4, darf ein Stein 4 oder höher gespielt werden.

Numeric Paper Cards

Papierkarten sind die Konterkarten gegen Stein und reichen von 1 bis 9.
Sie besiegen Steinkarten, verlieren jedoch gegen Scherenkarten.
Eine Papierkarte darf nur auf eine Karte gelegt werden, die entweder Papier oder Stein ist.
Die neue Karte muss dabei den gleichen oder einen höheren Zahlenwert besitzen.
Beispiel: Liegt ein Papier 5, darf ein Papier 5 oder höher gespielt werden.

Special Cards

Spezialkarten zwingen den nächsten Spieler, zwei oder vier Karten zu ziehen - es sei denn, er kann die vorherige Spezialkarte schlagen.
Beispiel: Liegt eine "Draw 2" vom Typ Schere, kann nur eine "Draw 2" vom Typ Stein daraufgelegt werden. Andernfalls muss der Spieler zwei Karten ziehen.
